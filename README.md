# Meraki Entertainment — Website Demo

Production-quality website demo for **Meraki Entertainment**, Nagaland.

Events · Pageants · Talent · Entertainment

## Features

- Cinematic hero and editorial homepage
- Featured event (Mr Dimapur)
- Events, Pageants, Contestants directory, Hall of Fame / Legacy
- Gallery, Video section, Media / Press
- Sponsorship / Partner section
- Contestant registration form
- Contact form with enquiry types
- Sticky navigation + mobile menu
- Premium black / warm-white / gold aesthetic
- SEO metadata ready

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS v4
- Google Fonts: Playfair Display + Inter

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
